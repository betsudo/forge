Use the existing Passport qualifier and SDK proof harness. Parameterize platform
cohort inputs without rewriting historical macOS receipts. A Linux entrypoint
refuses nonnative hosts before writes, checks independently pinned tools/source/
parameters, owns a fresh scratch tree and creates its own monotonic official/off
baseline. Run independent artifacts, cold/warm compilation and recovery through
the existing real proof path. Kill process groups on timeout. Store a passed
receipt only after successful checks and owned cleanup. Preserve exact scope:
52 artifact sets, two application proof scenarios.

The CI collector starts from a frozen complete job roster, not successful rows.
Retain terminal GitHub metadata, every attempt, failed/cancelled/missing jobs and
raw receipt hashes. Validate sequential stage intervals, actual compressed
transport bytes and terminal whole-job duration before invoking the existing
reporter. An unavailable transport uses official generation with cache:null;
integrity/identity/auth failures never qualify as availability fallback.
No hosted trial is started. Reusable cache promotion requires terminal success;
candidate uploads alone do not establish successful reusable publication.

A separate local payload tool wraps existing verified Forge snapshots in a
reproducible gzip/tar stream. It does not implement a second cache, archive-based
trust model or GitHub client. Explicit compressed/expanded limits and pinned
payload hash precede extraction; existing Forge restore remains the authority
for snapshot identity, profile, partition and payload bytes. Network measurement
must count this exact envelope separately; archive size alone is not transfer.
