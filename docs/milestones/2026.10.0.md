## Acceptance

- Full native Nix bootstrap checks, strict descriptor controls and v2/v3 real
  exported/downloaded/restored proof, verification and negative controls pass.
- Installer local fake-gh tests cover checksum/path/conflict, live/killed lock,
  activation interruption, retry and rollback; candidate provenance comes from a
  clean exact-commit Nix build. No release publication is implied.
- Research uses primary sources, exact consumer/tool pins, measured-versus-projected
  labels, unchanged proof/assertion counts and separate key/proof/provider concerns.
- Independent review blockers are resolved and evidence/spec tasks identify gaps.
- Signed Conventional Commits include DCO, issue refs and Assisted-by: AI.

## Separate release gates

Clean no-Nix consumer-host installation, dependency-license audit and real private
release downloading remain required before portable-binary release readiness.
Linux and other unexecuted architectures require their own runtime/proof receipts;
flake evaluation alone is insufficient. End-to-end DID/passport CI savings need
qualified compiler/backend mappings, full prerequisites and repeated measurements.
Proof-relay implementation, hosted registry, deployment, publication and Compact
integration need their own approved increments. All current work stays local;
GitHub issue/milestone metadata changes are the only current external writes.
