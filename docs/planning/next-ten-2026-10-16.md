## Hosting direction

First candidate: a small **Rust/Wasm Cloudflare Worker + D1 metadata + R2 object
storage + CDN/custom domain**, initially serving artifacts generated by qualified
native Forge CLI/CI workers. Immutable manifests alone may remove the need for
D1 in the first static delivery slice. Choose a database only when mutable catalog,
lookup or publication state requires it. Do not put the native cryptography graph
or expensive key generation in a small HTTP Worker request.

Native Rust Lambda alternative: **AWS Lambda + DynamoDB + S3 + CloudFront**.
This has a native runtime path but more independently priced components. The
shortlist is not a demonstrated globally cheapest solution or a deployment.
See [the current hosting recommendation](hosting-2026-10-16.md) and original
[hosting research](../research/hosting-costs.md). Measure useful compression;
canonical identity remains over original serialized bytes.
